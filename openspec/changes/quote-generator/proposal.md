# Proposal

## Why

The starter Vue app has no app-specific page yet. A small quote page provides a useful first feature and demonstrates navigation and interactive state in the single-page app.

## What Changes

- Add a quote page that displays a quote from an in-page collection.
- Let users choose another quote at random.
- Expose the page at `/quote`.

## Capabilities

### New Capabilities
- `quote-display`: Displaying quotes and selecting a random quote.

### Modified Capabilities

## Impact

- Vue app components and Vue Router configuration.
- No new dependencies or external services.
